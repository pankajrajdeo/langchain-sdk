# LangSmith for Coding Agents: Now track spend by outcome

- Increase the ROI of your coding agent spend by tracking and measuring outcomes, like pull requests, for your coding agents.
- A new concept called outcomes links GitHub pull requests or GitLab merge requests to threads, so you can see what a merged PR cost and how much spend never led to one.
- Every PR links back to the threads behind it, so you can investigate what's driving agent cost and how changes impact it.
