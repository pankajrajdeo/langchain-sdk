# Protect sensitive data in your traces: new controls in LangSmith

- **Control input and output access: **engineers can debug with run trees, performance statistics like latency and cost, and other trace data without seeing sensitive inputs and outputs
- **Manage access by user groups: **organize users into groups within LangSmith and set data access and workspace membership on a group-by-group basis**‍**
- **Create trace-level policies: **use root run metadata on your traces to determine which users can see them
