# How Credit Genie uses OpenWiki to keep codebase knowledge fresh, searchable, and automated

- **OpenWiki turned documentation into part of the development lifecycle.** Credit Genie uses OpenWiki to automatically generate and update docs based on code changes.
- **Helps people and coding agents.** Engineers use OpenWiki to understand unfamiliar systems, and coding agents check the `openwiki/` folder before making changes.
- **Eliminates tribal knowledge.** Important context is no longer locked with individual contributors, making onboarding and cross-functional collaboration easier.
