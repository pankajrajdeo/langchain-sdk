# Tool integrations

> Integrate with tools using LangChain JavaScript.

[Tools](../langchain/tools.md) are utilities designed to be called by a model: their inputs are designed to be generated by models, and their outputs are designed to be passed back to models.

A [toolkit](../langchain/tools.md#prebuilt-tools) is a collection of tools meant to be used together.

## Web search

The following table shows tools that execute online searches in some shape or form:

| Tool/Toolkit | Free/Paid | Return Data |
| - | - | - |
| [Diffbot](https://github.com/diffbot/langchain-diffbot) | Free | URL, Snippet, Title, Date, Knowledge Graph (Organizations, News, People, Places, Deals) |
| [Exa Search](tools/exa_search.md) | 1000 free searches/month | URL, Author, Title, Published Date |
| [Nia Toolkit](tools/nia.md) | Free tier available | Code, Docs, Metadata, Sources |
| [Perplexity Search](tools/perplexity_search.md) | Paid (with monthly free tier) | URL, Title, Snippet, Date, Last Updated |
| [TalorData SERP](https://docs.talordata.com/serp-api/integration/sdk-integration/how-to-set-up-talordata-with-langchain) | Paid | Title, URL, snippet, position, knowledge graph, answer box, AI overview |
| [Tavily Search](tools/tavily_search.md) | 1000 free searches/month | URL, Content, Title, Images, Answer |
