# detail

> **Attribute** in `langchain_core`

📖 [View in docs](https://reference.langchain.com/python/langchain-core/prompt_values/ImageURL/detail)

Specifies the detail level of the image.

Defaults to ``'auto'`` if not specified. Higher detail levels consume
more tokens but provide better image understanding.

## Signature

```python
detail: Literal['auto', 'low', 'high']
```
