# encoding

> **Attribute** in `langchain_core`

📖 [View in docs](https://reference.langchain.com/python/langchain-core/documents/base/Blob/encoding)

Encoding to use if decoding the bytes into a string.

Uses `utf-8` as default encoding if decoding to string.

## Signature

```python
encoding: str = 'utf-8'
```
