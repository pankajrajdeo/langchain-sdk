# template_format

> **Attribute** in `langchain_core`

📖 [View in docs](https://reference.langchain.com/python/langchain-core/prompts/few_shot_with_templates/FewShotPromptWithTemplates/template_format)

The format of the prompt template.

Options are: `'f-string'`, `'jinja2'`, `'mustache'`.

## Signature

```python
template_format: PromptTemplateFormat = 'f-string'
```
