# INTERNAL_CALL_METADATA_KEY

> **Attribute** in `langchain`

📖 [View in docs](https://reference.langchain.com/python/langchain/agents/middleware/internal_call_transformer/INTERNAL_CALL_METADATA_KEY)

Metadata key marking a model call as internal to middleware.

Kept separate from `lc_source` so filtering doesn't affect its existing
semantics.

## Signature

```python
INTERNAL_CALL_METADATA_KEY = 'lc_internal_call'
```
